## 🧠 Sobre mim

Sou um desenvolvedor com sólida experiência em **PHP, MySQL e Power BI**, atuando na automação de processos empresariais, integração entre sistemas e criação de dashboards inteligentes.  

Gosto de transformar códigos confusos em soluções elegantes, aplicar boas práticas de arquitetura (**PSR, Object Calisthenics, Clean Code**) e dar vida a dados por meio de relatórios e visualizações claras.

Trabalho com um ecossistema integrado de ferramentas como **HubSpot, Pipedrive, BoondManager, SmartRecruiters, Personio e Pentaho**, criando pipelines ETL, APIs de integração e rotinas de análise.
